## Ejercicio 6. Generador de estadísticas

Crea un programa que permita obtener diferentes estadísticas a partir de una colección de números.

```
const numbers = [12, 5, 8, 20, 3, 15, 10, 7, 18, 4];
```

### Requisitos

Implementa funciones independientes para:

- Obtener el número más alto.
- Obtener el número más bajo.
- Calcular la media.
- Contar cuántos números son pares.
- Obtener un nuevo array con los números superiores a un valor determinado.

### Testing

Una vez implementadas las funciones:

- Instala Vitest.
- Crea un archivo de tests.
- Implementa al menos un test para cada función.
- Comprueba que los resultados obtenidos son los esperados.
- Prueba también algunos casos límite, como un array vacío.
